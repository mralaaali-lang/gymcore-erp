# دليل لوحة تحكم المشرف العام (Super Admin Dashboard)

## 📋 نظرة عامة

لوحة تحكم المشرف العام هي الواجهة الأساسية لإدارة المنصة بالكامل (GymCore ERP). توفر هذه اللوحة أدوات شاملة لإدارة جميع الصالات الرياضية (التينانتس)، المستخدمين، الفواتير، الأمان، التقارير، والتسويق.

**المسار الأساسي:** `/super-admin`

---

## 🔹 1. لوحة المعلومات الرئيسية (Dashboard)

**المسار:** `/super-admin/dashboard`

الصفحة الرئيسية التي تعرض نظرة شاملة عن أداء المنصة.

### المكونات الرئيسية:
- **بطاقات الأداء (Metric Cards):**
  - إجمالي الصالات (Total Gyms) — مع رسم بياني مصغر (Sparkline)
  - إجمالي الأعضاء (Total Members)
  - الإيرادات الشهرية (Monthly Revenue)
  - الصالات النشطة (Active Gyms)
  - الإشتراكات المنتهية (Expired Subscriptions)
- **جدول الصالات:** قائمة بجميع الصالات مع إمكانية البحث والفلترة
- **أزرار الإجراءات:**
  - إضافة صالة جديدة (Add Gym)
  - بحث/فلترة الصالات
  - تحديث البيانات (Refresh)
  - حظر/إلغاء حظر صالة
  - عرض/إخفاء التفاصيل
  - رابط الانتقال السريع

---

## 🔹 2. التقارير (Reports)

**المسار:** `/super-admin/reports`

لوحة التقارير الأساسية للمنصة — تعرض إحصائيات مجمعة عبر جميع التينانتس.

### التبويبات (5):

| التبويب | الوصف |
|---------|-------|
| **نظرة عامة** | ملخص المؤشرات الرئيسية (إجمالي الصالات، الأعضاء، الإيرادات) |
| **الاشتراكات** | تحليل خطط الاشتراك وتوزيعها بين الصالات |
| **الإيرادات** | الرسوم البيانية للإيرادات (شهرية، سنوية) |
| **الصالات** | إحصائيات خاصة بالصالات (نشطة، متوقفة، جديدة) |
| **الأعضاء** | تحليل قاعدة الأعضاء (نمو، توزيع) |

### العناصر المشتركة:
- رسوم بيانية (أعمدة، خطوط، دائرية) باستخدام Recharts
- أزرار تحميل التقارير (Download)
- تحديث البيانات
- تنسيق العملات والأرقام

---

## 🔹 3. تقارير متقدمة (Advanced Reports)

**المسار:** `/super-admin/reports/advanced`

تقارير تحليلية متقدمة مع 6 تبويبات.

### التبويبات (6):

| التبويب | الوصف |
|---------|-------|

| **أداء الباقات** | تحليل أداء خطط الاشتراك المختلفة |

| **ترتيب الصالات** | ترتيب الصالات حسب الأداء والإيرادات |

### الأزرار والعمليات:
- تحميل كل تقرير بصيغة PDF/Excel
- تصدير البيانات
- تحديث التحليلات

## 🔹 5. تذاكر الدعم (Support Tickets)

**المسار:** `/super-admin/support`

نظام تذاكر دعم مركزي للمنصة.

### التبويبات (3):

| التبويب | الوصف |
|---------|-------|
| **التذاكر** | إدارة تذاكر الدعم — عرض، تصفية، تعيين، حل |
| **التحليلات** | إحصائيات أداء فريق الدعم (معدل الحل، وقت الاستجابة) |
| **قاعدة المعرفة** | مقالات تعليمات ومساعدة قابلة للإضافة/التعديل/الحذف |

### العمليات في التذاكر:
- **حالة التذكرة:** مفتوحة (open) | قيد المعالجة (in_progress) | محلولة (resolved) | مغلقة (closed)
- **أولوية التذكرة:** منخفضة (low) | متوسطة (medium) | عالية (high) | حرجة (critical)
- **إجراءات:**
  - بحث عن تذكرة
  - تصفية حسب الحالة والأولوية
  - تعيين تذكرة لمشرف (assign)
  - إلغاء تعيين (unassign)
  - تغيير الحالة
  - تقييم الحل (rating)
  - إضافة تعليقات وملاحظات

## 🔹 13. الأمان (Security Center)

**المسار:** `/super-admin/security`

مركز الأمان — إدارة أمان المنصة.

### التبويبات (2):

#### التبويب الأول: نظرة عامة (Overview)
- **بطاقة حالة الأمان:** حالة عامة (آمن / متوسط / خطر)
- **إحصائيات الأمان:**
  - عدد جلسات المشرفين النشطة
  - محاولات تسجيل الدخول الفاشلة (آخر 24 ساعة)
  - التنبيهات الأمنية المعلقة
  - إجمالي الأحداث الأمنية
- **جدول الجلسات النشطة:**
  - قائمة بجلسات المشرفين النشطة
  - عرض (البريد الإلكتروني، عنوان IP، تاريخ آخر نشاط، الجهاز/المتصفح)
  - زر **إنهاء الجلسة** (Revoke)

#### التبويب الثاني: الحماية (Protection)
- **قسم سياسة كلمة المرور:**
  - الحد الأدنى لطول كلمة المرور
  - متطلبات الأحرف (كبيرة، صغيرة، أرقام، رموز)
  - صلاحية كلمة المرور (عدد الأيام)
  - عدد المحاولات الفاشلة المسموحة
  - زر **حفظ إعدادات كلمة المرور**

- **قسم إعدادات الحماية:**
  - تفعيل/إيقاف المصادقة الثنائية (2FA) للمشرفين
  - قائمة الـ IP المسموح بها (Whitelist)
  - تفعيل حدود الطلبات (Rate Limiting)
  - إعدادات الحماية المتقدمة
  - زر **حفظ إعدادات الحماية**

## 🔹 16. إنشاء صالة جديدة (Create Gym Wizard)

**المسار:** `/super-admin/tenants/new`

### الحقول:
- **معلومات الصالة:** اسم الصالة، الاسم التجاري (DBA)

- **خطة الاشتراك:** اختيار الباقة المناسبة
- **زر الإنشاء:** إرسال البيانات لإنشاء الصالة عبر API

| **الخادم** | أداء الخادم — استخدام CPU، RAM، التخزين |
| **الأحداث** | سجل أحداث النظام والخدمات |

### العناصر:
- أيقونات حالة (Activity, Database, Server, Bell)

- فحوصات الصحة (Health Checks)
