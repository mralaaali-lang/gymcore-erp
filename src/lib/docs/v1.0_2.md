# تقرير مراجعة جودة بنية "جيماوي" v1.0 (QA & Architecture Audit)

بصفتي Lead Software Architect، قمت بفحص تدفق البيانات بين الـ 34 شاشة، وإليك التقرير الفني:

## 1. تحليل نقاط الضعف المنطقية (Front-End Edge Cases)
*   **عزلة البيانات (Data Isolation Leak):** تم رصد مخاطر في تخزين الـ LocalStorage حيث يجب عزل `cached_membership` ببادئة `gymId` لمنع تداخل البيانات عند استخدام نفس المتصفح لأكثر من جيم.
*   **مزامنة الهوية (Branding Sync):** كانت بعض الشاشات تعتمد على هارد-كود (Hardcoded) للوجو المنصة بدلاً من القيمة المستمدة من الـ Context.
*   **إدارة الحالة في الـ Zero-State:** الجيم الجديد يفتقر لمسار توجيهي (Onboarding Flow) واضح يربط بين تحديث الهوية (Settings) وأول عملية إدخال (Packages).

## 2. الهيكلية المحدثة (Architectural Upgrades)
*   **White-Labeling Engine:** تم بناء نظام مراقبة (Observer Pattern) داخل الـ React Context يقوم ببث تحديثات اسم ولوجو الجيم فور حفظها.
*   **Theme & Locale Orchestrator:** إضافة دعم حقيقي للـ CSS Variables و `dir="rtl/ltr"` لضمان سلاسة التحول بين اللغات والثيمات دون إعادة تحميل الصفحة.

# كود إدارة الحالة المركزية (GymBrandContext.tsx)

```typescript
import React, { createContext, useContext, useState, useEffect } from 'react';

// تعريف الأنواع الصارمة
interface GymSettings {
  name: string;
  logo: string;
  primaryColor: string;
}

interface GymBrandState {
  currentGymId: string;
  brand: GymSettings;
  theme: 'light' | 'dark';
  language: 'ar' | 'en';
  isZeroState: boolean;
}

interface GymBrandContextType extends GymBrandState {
  updateBrand: (newBrand: Partial<GymSettings>) => void;
  toggleTheme: () => void;
  toggleLanguage: () => void;
  switchGym: (gymId: string) => void;
}

const GymBrandContext = createContext<GymBrandContextType | undefined>(undefined);

export const GymBrandProvider: React.FC<{ children: React.ReactNode }> = ({ children }) => {
  const [state, setState] = useState<GymBrandState>({
    currentGymId: 'GYM-P-101',
    brand: {
      name: 'جيماوي بريميوم',
      logo: '{{DATA:IMAGE:IMAGE_LOGO_PLACEHOLDER}}',
      primaryColor: '#f97316',
    },
    theme: 'light',
    language: 'ar',
    isZeroState: false,
  });

  // مزامنة التغييرات مع الـ DOM
  useEffect(() => {
    document.documentElement.dir = state.language === 'ar' ? 'rtl' : 'ltr';
    document.documentElement.lang = state.language;
    if (state.theme === 'dark') {
      document.documentElement.classList.add('dark');
    } else {
      document.documentElement.classList.remove('dark');
    }
  }, [state.theme, state.language]);

  const updateBrand = (newBrand: Partial<GymSettings>) => {
    setState(prev => ({ ...prev, brand: { ...prev.brand, ...newBrand } }));
  };

  const toggleTheme = () => {
    setState(prev => ({ ...prev, theme: prev.theme === 'light' ? 'dark' : 'light' }));
  };

  const toggleLanguage = () => {
    setState(prev => ({ ...prev, language: prev.language === 'ar' ? 'en' : 'ar' }));
  };

  const switchGym = (gymId: string) => {
    // محاكاة تبديل الجيم وتغيير الحالة الصفرية
    const isNew = gymId === 'NEW-GYM-000';
    setState(prev => ({
      ...prev,
      currentGymId: gymId,
      isZeroState: isNew,
      brand: isNew ? { name: 'جيم جديد', logo: '', primaryColor: '#f97316' } : prev.brand
    }));
  };

  return (
    <GymBrandContext.Provider value={{ ...state, updateBrand, toggleTheme, toggleLanguage, switchGym }}>
      <div className={state.language === 'ar' ? 'font-arabic' : 'font-sans'}>
        {children}
      </div>
    </GymBrandContext.Provider>
  );
};

export const useGymBrand = () => {
  const context = useContext(GymBrandContext);
  if (!context) throw new Error('useGymBrand must be used within GymBrandProvider');
  return context;
};
```
